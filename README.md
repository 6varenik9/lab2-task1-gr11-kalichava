## Overview
Программа на языке C, которая генерирует массив натуральных чисел заданной длины и выводит те из них, которые являются полными квадратами. Массив заполняется случайными числами. Проверка "полный квадрат или нет" реализована в отдельной функции.

## Usage
При запуске программа принимает 1 аргумент — размер массива.

Пример:
```bash
./labrabota3-1 10
```

Вывод:
- Сгенерированный массив
- Найденные полные квадраты

## Building
gcc src/main.c -o labrabota3-1
